# Вопросы по лабе

1. Зачем писать .model small?
2. Зачем писать каждый раз 0DH в строке?
3. Как работает ввод строки?
4. Зачем пушить регистры в стек?


1. Модель определяет организацию сегментов (данные, код, стек) в программе.
Конкретно small создает сегмент кода и данных <= 64 Кбайт.

2. Дело в том, что 0Ah - перевод на новую строку, а 0Dh - перевод каретки в начало. Коомбинация этих управляющих символов, должны дать нужный результат. Однако в DosBox можно использовать просто 0Ah, это такой unix подход, хотя в оригнальном MS-DOS нужно использовать 0Dh 0Ah.

3. Нужно разобраться как работает ввод строки.
Начнём с объявления строки в памяти, мы делим ее на две части заголовок и данные строки.
Заголовок хранит максимальную длину и реально считанную длину.

```
STR1HEAD DB 50h, 0  ; Заголовок
STR1 DB 80 DUP('*'), 0Ah, '$'  ; Данные
```

```
Адрес:    buffer   buffer+1  buffer+2  buffer+3  buffer+4  ...
Байт:     [maxlen] [  0   ]  [  ???  ] [  ???  ] [  ???  ] ...
           ↑        ↑         ↑
           |        |         └─ Здесь будут символы
           |        └─────────── Сюда DOS запишет реальную длину
           └──────────────────── Максимальная длина (мы задаём)
```
